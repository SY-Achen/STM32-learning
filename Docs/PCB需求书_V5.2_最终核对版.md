## 1. 板子规格(硬性)

| 项目 | 要求 |
|------|------|
| 尺寸 | **100 × 70 mm** |
| 层数 | **2 层 FR-4** |
| 铜厚 | **2 oz** |
| 板厚 | 1.6mm |
| 表面工艺 | 无铅 HASL |
| 阻焊 | 绿色 |
| 安装孔 | 4 × M3(四角,离边 ≥5mm) |

## 2. 板子定位

STM32 最小系统板(**Blue Pill,STM32F103C8T6**)作为模块**插在主板上的排针母座**上。
主板不焊 MCU/LDO/晶振,只负责:电源分配 + 外部模块接口 + 保护电路。

## 3. 接口需求

| 接口 | 类型 | 说明 |
|------|------|------|
| **J_MCU** | **2.54mm 双排 2×20 排针母座(直插)** | ⭐ 核心!Blue Pill 插入,预留 57×27mm 区域 |
| J1 | H桥模块接口 | 1×6 排针(2.54mm):IN1/IN2/IN3/IN4/COM/24V |
| J2 | 舵机接口 | 1×3 排针:VCC/GND/信号 |
| J3 | 光敏接口 | 1×3 排针:VCC/GND/触点 |
| J4 | SWD 调试 | 1×4 排针:SWDIO/SWCLK/GND/3.3V |
| 电源输入 | 螺丝端子或排针 | 24V + / 5V + / GND 各一个 |

## 4. Blue Pill 排母引脚分配(只连这些,其余悬空)

**依据:固件 v1.7 源码引脚定义(已核对)**

| 排母脚(Blue Pill) | 网络 | 去向 | 固件功能 |
|-------------------|------|------|---------|
| PA0 | PA0 | 光敏输入(经保护→J3) | 光敏信号,上拉输入,**高电平=触发** |
| PA1 | PA1 | H桥 IN1(经保护→J1) | 推杆正转上桥 |
| PA2 | PA2 | H桥 IN2(经保护→J1) | 推杆正转下桥 |
| PA5 | PA5 | H桥 IN4(经保护→J1) | 推杆反转下桥 |
| PA6 | PA6 | 舵机 PWM(经保护→J2) | TIM3_CH1,50Hz,500~1833µs |
| PA7 | PA7 | H桥 IN3(经保护→J1) | 推杆反转上桥 |
| PA13 | SWDIO | → J4.1 | 烧录 |
| PA14 | SWCLK | → J4.2 | 烧录 |
| NRST | NRST | 10kΩ上拉 3V3 + 100nF→GND | 复位 |
| 3V3 | 3V3 | 仅作上拉参考(Blue Pill 自己出 3.3V) | — |
| 5V | 5V | 主板 5V 供电(经 F4=1A) | 供电 |
| GND | GND | 共地 | — |

> 其余 28 脚:悬空(NC)
> PC13(LED)在 Blue Pill 板上,主板不需要引。

## 5. 电源网络

```
24V 输入 → [F1 4A] → J1 电源脚, TVS(SMBJ26A)跨接 24V-GND
5V 输入  → [F2 5A] → 5V 总线
              ├→ [F4 1A] → 排母 5V 脚 (Blue Pill 供电)
              ├→ [F3 3A] → J2.VCC (舵机)
              └→ [F5 0.5A] → J3.VCC (光敏)
GND:所有地星形汇聚,单点共地
```

## 6. H桥模块接线(5A 单路 GZ-PMDC-120A7T)

**真值表(固件按此驱动):**

| IN1 | IN2 | IN3 | IN4 | 电机 |
|-----|-----|-----|-----|------|
| 1 | 0 | 1 | 0 | 正转(伸出) |
| 0 | 1 | 0 | 1 | 反转(缩回) |
| 全 0 | | | | 停止 |

**⚠️ 禁止组合:IN1&IN2 同时=1、IN3&IN4 同时=1 → 烧 MOS!**

| 模块端子 | 接到主板 |
|---------|---------|
| IN1 | PA1(经 1kΩ + 100kΩ下拉) |
| IN2 | PA2(经 1kΩ + 100kΩ下拉) |
| IN3 | PA7(经 1kΩ + 100kΩ下拉) |
| IN4 | PA5(经 1kΩ + 100kΩ下拉) |
| COM | GND(**必须接地**,外部取电) |
| 12-24V+ | 24V(经 F1=4A + SMBJ26A) |
| 12-24V− | GND |
| 电机+ / 电机− | 推杆红/黑(经 10A 保险丝) |
| 5V 输出 | **不接**(内部取电才用) |

| 网络 | 连接 |
|------|------|
| PA0 | J3 触点 → 1kΩ串 → 10kΩ上拉(3V3)→ 排母 PA0 |
| PA1 | 排母 PA1 → 1kΩ → J1.IN1 + 100kΩ下拉 + ESD |
| PA2 | 排母 PA2 → 1kΩ → J1.IN2 + 100kΩ下拉 + ESD |
| PA5 | 排母 PA5 → 1kΩ → J1.IN4 + 100kΩ下拉 + ESD |
| PA6 | 排母 PA6 → 220Ω → J2 信号 + 100kΩ下拉 |
| PA7 | 排母 PA7 → 1kΩ → J1.IN3 + 100kΩ下拉 + ESD |

## 8. 走线要求

| 网络 | 线宽 | 说明 |
|------|------|------|
| 24V 功率 | ≥2.0mm (2oz) | 峰值 2.5A |
| 24V GND | ≥2.0mm | 星形接地 |
| 5V 总线 | ≥1.0mm | 舵机峰值 1.5A |
| H桥电机输出 | ≥2.0mm | 2.5A 峰值 |
| 信号线 | 0.3mm | 短走线,远离 24V |
| GND | **底层完整覆铜** | 必须 |
| 24V vs 信号间距 | ≥1.0mm | |

## 9. 注意事项(已核对固件 v1.7)

1. **引脚按固件 v1.7**:PA1=IN1、PA2=IN2、PA7=IN3、PA5=IN4(不是 PB12/PB13!)
2. **光敏触发逻辑**:PA0 高电平=触发(光敏暗时继电器闭合拉高)
3. **舵机**:PA6 = TIM3_CH1 PWM,50Hz,脉宽 500~1833µs(270°舵机前180°)
4. Blue Pill 外挂:主板只放 2×20 排母,不焊 MCU/LDO/晶振
5. 信号 GND 与功率 GND 单点共地(星形)
6. H桥模块 5V 输出端不用,COM 必须接地
7. 所有信号线加下拉(复位时模块不动作)
8. 排母位置四周留 ≥2mm,底部避开走线(Blue Pill 投影 53.3×22.5mm)
9. **主板不需要接 8MHz 晶振**——Blue Pill 自带,固件用 HSI 内部时钟
10. 推杆电机输出端(主板到 J1)务必按 10A 保险丝设计
