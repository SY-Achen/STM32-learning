# 吹雪机控制板 PCB 需求书 (V5.1 精简版)

> 2026-08-18 | 交给画板人 | 只需板子需求,不含元件清单

---

## 1. 板子规格(硬性)

| 项目 | 要求 |
|------|------|
| 尺寸 | **100 × 70 mm** |
| 层数 | **2 层 FR-4** |
| 铜厚 | **2 oz** |
| 板厚 | 1.6mm |
| 表面工艺 | 无铅 HASL |
| 阻焊 | 绿色 |
| 安装孔 | 4 × M3(四角,离边 ≥5mm) |

## 2. 板子定位

STM32 最小系统板(**Blue Pill**)作为模块**插在主板上的排针母座**上。
主板不焊 MCU/LDO/晶振,只负责:电源分配 + 外部模块接口 + 保护电路。

## 3. 接口需求

| 接口 | 类型 | 说明 |
|------|------|------|
| **J_MCU** | **2.54mm 双排 2×20 排针母座(直插)** | ⭐ 核心!Blue Pill 插入,预留 57×27mm 区域 |
| J1 | H桥模块接口 | 1×6 排针(2.54mm):IN1/IN2/IN3/IN4/COM/24V |
| J2 | 舵机接口 | 1×3 排针:VCC/GND/信号 |
| J3 | 光敏接口 | 1×3 排针:VCC/GND/触点 |
| J4 | SWD 调试 | 1×4 排针:SWDIO/SWCLK/GND/3.3V |
| 电源输入 | 螺丝端子或排针 | 24V + / 5V + / GND 各一个 |

## 4. Blue Pill 排母引脚分配(只连这些,其余悬空)

| 排母脚(Blue Pill) | 网络 | 去向 |
|-------------------|------|------|
| PA0 | PA0 | 光敏输入(经保护电路→J3) |
| PA1 | PA1 | H桥 IN1(经保护→J1) |
| PA2 | PA2 | H桥 IN2(经保护→J1) |
| PA5 | PA5 | H桥 IN4(经保护→J1) |
| PA6 | PA6 | 舵机 PWM(经保护→J2) |
| PA7 | PA7 | H桥 IN3(经保护→J1) |
| PA13 | SWDIO | → J4.1 |
| PA14 | SWCLK | → J4.2 |
| NRST | NRST | 10kΩ上拉 3V3 + 100nF→GND |
| 3V3 | 3V3 | 仅作上拉参考(Blue Pill 自己出 3.3V) |
| 5V | 5V | 主板 5V 供电(经 F4=1A) |
| GND | GND | 共地 |

> 其余 28 脚:悬空(NC)

## 5. 电源网络

```
24V 输入 → [F1 4A] → J1 电源脚, TVS(SMBJ26A)跨接 24V-GND
5V 输入  → [F2 5A] → 5V 总线
              ├→ [F4 1A] → 排母 5V 脚 (Blue Pill 供电)
              ├→ [F3 3A] → J2.VCC (舵机)
              └→ [F5 0.5A] → J3.VCC (光敏)
GND:所有地星形汇聚,单点共地
```

## 6. 信号网络(同名网络连通即可)

| 网络 | 连接 |
|------|------|
| PA0 | J3 触点 → 1kΩ串 → 10kΩ上拉(3V3)→ 排母 PA0 |
| PA1 | 排母 PA1 → 1kΩ → J1.IN1 + 100kΩ下拉 + ESD |
| PA2 | 排母 PA2 → 1kΩ → J1.IN2 + 100kΩ下拉 + ESD |
| PA5 | 排母 PA5 → 1kΩ → J1.IN4 + 100kΩ下拉 + ESD |
| PA6 | 排母 PA6 → 220Ω → J2 信号 + 100kΩ下拉 |
| PA7 | 排母 PA7 → 1kΩ → J1.IN3 + 100kΩ下拉 + ESD |

## 7. 走线要求

| 网络 | 线宽 | 说明 |
|------|------|------|
| 24V 功率 | ≥2.0mm (2oz) | 峰值 2.5A |
| 24V GND | ≥2.0mm | 星形接地 |
| 5V 总线 | ≥1.0mm | 舵机峰值 1.5A |
| H桥电机输出 | ≥2.0mm | 2.5A 峰值 |
| 信号线 | 0.3mm | 短走线,远离 24V |
| GND | **底层完整覆铜** | 必须 |
| 24V vs 信号间距 | ≥1.0mm | |

## 8. 注意事项

1. 引脚按固件 v1.7:PA1=IN1、PA2=IN2、PA7=IN3、PA5=IN4
2. Blue Pill 外挂:主板只放 2×20 排母,不焊 MCU/LDO/晶振
3. 信号 GND 与功率 GND 单点共地(星形)
4. H桥模块 5V 输出端不用,COM 必须接地
5. 所有信号线加下拉(复位时模块不动作)
6. 排母位置四周留 ≥2mm,底部避开走线(Blue Pill 插入投影 53.3×22.5mm)

## 9. 交付物

EasyEDA 工程 / Gerber+钻孔 / BOM / 3D 预览(检查 Blue Pill 插入不碰撞)

## 10. 验收

- Netlist/Connection/Clearance = 0
- 3D 无碰撞(Blue Pill 插入区)
- 2oz 铜厚、底层覆铜完整
