# 吹雪机控制系统 — 完整接线图(双 H 桥模块版)

> 版本:V2.0 (2026-08-08) | 依据:双 H 桥电机驱动模块 7A160W 实物端子 + 使用说明 + STM32F103C8T6 固件引脚
> 适用:当前实物硬件(24V 推杆 / 270° 舵机 / 5V 光敏 / 双 H 桥模块)

---

## 1. 系统总览(文字版)

```
大疆14S电池 (51.8~58.8V)
   │
   ├──→ DC-DC1 (30~90V→24V/5A/120W) ──→ [F1 4A] ──→ 模块 6.5~27V 电源+  ┐
   │        (非隔离, 输出地=电池负极)      (可选15A)     模块 PGND      │ 功率侧
   │                                                                   │
   └──→ DC-DC2 (15~90V→5V/8A/40W) ──→ 5V 总线                          │
            (非隔离, 输出地=电池负极)     ├─→ [F4 1A] ─→ STM32 5V 引脚   │
                                         ├─→ [F3 3A] ─→ 舵机红线(VCC)   │
                                         ├─→ [F5 0.5A]→ 光敏模块 VCC    │
                                         └─→ [F6 0.5A]→ 模块 +5V 参考端 │
                                                      (3.3V单片机接3.3V) │
                                                                       │
  模块 1# 输出 A ──→ [10A 保险丝] ──→ 推杆红线(24V推杆)                  │
  模块 1# 输出 B ────────────────→ 推杆黑线                              │
  (2# 输出不用)
```

## 2. 双 H 桥模块端子接线表

### 2.1 功率侧(右侧端子)

| 模块端子 | 接到 | 线规 | 保险丝 |
|---------|------|------|--------|
| **6.5~27V 电源 +** | DC-DC1 输出 24V + | 16AWG | **F1 = 4A**(可选 15A) |
| **PGND** | DC-DC1 输出 −(电池负极) | 16AWG | — |
| **1# 输出 A** | 推杆红线 | 16AWG | **10A 保险丝** |
| **1# 输出 B** | 推杆黑线 | 16AWG | — |
| 2# 输出 A/B | 不接(悬空) | — | (10A 保险丝可留作备用) |

### 2.2 信号侧(左侧端子)

| 模块端子 | 接到 | 说明 |
|---------|------|------|
| **+5V**(参考电平) | **STM32 3.3V 引脚** | ⚠️ 3.3V 单片机接 3.3V!参考电平决定信号阈值 |
| **GND**(信号地) | STM32 GND | 与 MCU 共地 |
| **IN1** | STM32 **PA1** | 1# 电机正转(推杆伸出) |
| **IN2** | STM32 **PA2** | 1# 电机反转(推杆缩回) |
| **ENA1** | STM32 **PB14** | 使能(高有效,可 PWM 调速) |
| IN3 / IN4 / ENA2 | 不接(2# 电机不用) | 悬空 |
| PWM1 / I/O | 不接(外接 PWM 发生器用) | 悬空 |

> ⚠️ **丝印警告:信号端 GND 不能与功率端 PGND 直接共地**(模块内部二极管隔离)。接线时信号 GND 走 5V 地、PGND 走 24V 地,两者在电池负极自然汇合即可,不要在模块端人为短接。

## 3. STM32 引脚分配(与固件一致)

| STM32 引脚 | 功能 | 接到 | 保护 |
|-----------|------|------|------|
| PA0 | 光敏信号输入(上拉) | 光敏模块触点 COM | 10kΩ上拉 + 1kΩ串 + 100nF |
| PA6 | TIM3_CH1 舵机 PWM(50Hz) | 舵机信号线(橙/黄) | 220Ω串 + 100kΩ下拉 |
| PA1  | H桥 IN1(伸出) | 模块 IN1 | 1kΩ串 + 100kΩ下拉 |
| PA2  | H桥 IN2(缩回) | 模块 IN2 | 1kΩ串 + 100kΩ下拉 |
| PB14 | H桥 ENA(使能) | 模块 ENA1 | 1kΩ串 + 100kΩ下拉 |
| 5V | 板载供电 | DC-DC2 5V(经 F4=1A) | — |
| GND | 共地 | DC-DC2 地 | — |
| PA13/PA14 | SWD 下载 | ST-Link | — |

## 4. 各模块接线明细

### 4.1 DC-DC 降压模块

| 端子 | 接到 |
|------|------|
| DC-DC1 输入 + | 电池正极(51.8~58.8V) |
| DC-DC1 输入 − | 电池负极 |
| DC-DC1 输出 + | F1(4A)→ 模块 6.5~27V+ |
| DC-DC1 输出 − | 模块 PGND |
| DC-DC2 输入 + | 电池正极 |
| DC-DC2 输入 − | 电池负极 |
| DC-DC2 输出 + | 5V 总线(STM32/舵机/光敏/模块参考) |
| DC-DC2 输出 − | 5V 地(STM32 GND 等) |

### 4.2 舵机(270° 数字舵机,15kg)

| 舵机线 | 颜色 | 接到 |
|--------|------|------|
| VCC | 红 | 5V(经 F3=3A)→ 建议独立 1000µF 电解电容滤波 |
| GND | 棕/黑 | 5V 地 |
| 信号 | 橙/黄 | PA6(TIM3_CH1 PWM) |

> 脉宽 500~2500µs;固件已限 500~1833µs(前 180°)。0°=油门关,180°=油门最大。

### 4.3 光敏模块(5V 光敏继电器,暗时吸合)

| 端子 | 接到 |
|------|------|
| VCC | 5V(经 F5=0.5A) |
| GND | 5V 地 |
| 触点 COM/NO | PA0(经保护电路) |

> 光敏模块只提供**信号**,不直接驱动推杆/舵机——全部由 STM32 控制。

### 4.4 ST-Link 烧录

| ST-Link | STM32 |
|---------|-------|
| SWDIO | PA13 |
| SWCLK | PA14 |
| GND | GND |
| 3.3V | 3.3V(可选) |

## 5. 保险丝配置汇总(外接!)

| 编号 | 位置 | 规格 | 保护对象 |
|------|------|------|----------|
| F1 | DC-DC1 输出 → 模块电源 | 4A(或 15A) | 24V 总线 |
| F2 | DC-DC2 输出 → 5V 总线 | 5A | 5V 总线 |
| F3 | 5V → 舵机 | 3A | 舵机(堵转~1.5A×2) |
| F4 | 5V → STM32 | 1A | STM32 板 |
| F5 | 5V → 光敏 | 0.5A | 光敏模块 |
| F6 | 5V → 模块 +5V 参考端 | 0.5A | 模块信号端 |
| — | 模块 1# 输出 → 推杆 | **10A** | 推杆(客服要求外接) |
| — | 模块电源输入 | **15A** | 模块功率(客服要求外接) |

> 使用说明要求:电源输入端串联保险丝(15A 慢熔);电机接口串联 10A 保险丝——**这两颗在模块外部接**。

## 6. 使用注意事项(模块说明书)

1. **电源不能接反**,电压 6.5~27V,超压会烧模块
2. 电源输出电流建议 ≥ 电机额定电流 2 倍(推杆 2.5A 峰值 → 24V 电源 ≥5A,DC-DC1 满足)
3. **电机接口不能短路**(否则烧模块)→ 必须串 10A 保险丝
4. **正反转切换前必须先刹车 0.1S 以上**(固件已实现:actuator_stop 后再换向)
5. 模块掉电时不要高速转动电机(反电动势烧模块)
6. 驱动板 +5V 接参考电平:3.3V 单片机接 3.3V(本项目)
