# 吹雪机控制板 PCB 需求书 (V5, Blue Pill 外挂版)

> 版本:V5.1 (2026-08-18) | 用途:交给画板人 / 打板厂
> 设计工具:嘉立创EDA(EasyEDA)专业版,工程「吹雪机控制板V5」

---

## 1. 板子定位

**STM32 最小系统板(Blue Pill)作为模块插在主板上的控制板。**
主板不焊 MCU,通过 **2×20 排针母座** 插 Blue Pill;主板负责:
电源分配、H桥/舵机/光敏接口、保护电路(保险丝/TVS/ESD/滤波)。

---

## 2. 板子规格(硬性)

| 项目 | 要求 |
|------|------|
| 尺寸 | **100 × 70 mm** |
| 层数 | **2 层** FR-4 |
| 铜厚 | **2 oz**(内外层都 2oz) |

## 3. 系统架构

```
大疆14S电池 (51.8~58.8V)
   │
   ├──→ DC-DC1 (30~90V→24V/5A/120W) ──→ [F1 4A] ──→ H桥模块电源 + (12-24V)
   │                                            └─→ [D1 SMBJ26A] →GND
   │
   └──→ DC-DC2 (15~90V→5V/8A/40W) ──→ [F2 5A] ──→ 5V 总线
                                                  ├─→ [F4 1A] → 排母 J_MCU 5V 脚 (Blue Pill 供电)
                                                  ├─→ [F3 3A] → 舵机 VCC
                                                  ├─→ [F5 0.5A] → 光敏 VCC
                                                  └─→ 板载无 LDO(Blue Pill 自带)
```

**关键:主板不焊 LDO/晶振/去耦**——全部由 Blue Pill 承担。主板只把
5V 送给排母 5V 脚,Blue Pill 板载 AMS1117 出 3.3V 供自己。

---

## 4. Blue Pill 排母接口(J_MCU, 2×20 排针母座)

**Blue Pill(STM32F103C8T6 最小系统板)规格:**
- 尺寸:53.34 × 22.5 mm,排针 2×20(40脚),间距 2.54mm
- 排针**向下焊**(引脚朝主板),主板用**2×20 排针母座**承接
- 母座封装:2.54mm 双排母 40P(直插),焊在主板上

**排母引脚分配(只连这些,其余悬空):**

| 母座脚 | Blue Pill 引脚 | 连到主板网络 |
|--------|---------------|-------------|
| A 排(MCU 侧) | 3V3 | 3V3(母座内自连,实际用 Blue Pill 自带) |
| | PA0 | PA0(光敏输入) |
| | PA1 | PA1(H桥 IN1) |
| | PA2 | PA2(H桥 IN2) |
| | PA5 | PA5(H桥 IN4) |
| | PA6 | PA6(舵机 PWM) |
| | PA7 | PA7(H桥 IN3) |
| | PA13 | SWDIO → J4.1 |
| | PA14 | SWCLK → J4.2 |
| | NRST | R1(10k 上拉 3V3)+ C(100nF GND) |
| B 排 | 5V | 5V(经 F4=1A) |
| | GND | GND(共地) |
| | 其余 29 脚 | 悬空(NC) |

> ⚠️ Blue Pill 已自带:8MHz 晶振、AMS1117-3.3、复位按钮、BOOT0 跳线、
> 2×20 排针。主板**不要**重复放这些。

## 7. 走线要求(重要)

| 网络 | 线宽 | 说明 |
|------|------|------|
| 24V 功率 | **≥2.0mm** (2oz) | H桥电源,峰值 2.5A |
| 24V GND | ≥2.0mm | 星形接地 |
| 5V 总线 | ≥1.0mm | 舵机峰值 1.5A |
| H桥电机输出 | ≥2.0mm | 推杆 2.5A 峰值 |
| 信号线(PA0-7) | 0.3mm | 短走线,远离 24V |
| GND 覆铜 | **底层完整覆铜** | 必须 |
| 24V vs 信号间距 | ≥1.0mm | 安全间距 |

---

## 8. 注意事项(给画板人)

1. **引脚按固件 v1.7**:PA1=IN1、PA2=IN2、PA7=IN3、PA5=IN4
2. **Blue Pill 外挂**:主板只放 2×20 排母,不焊 MCU/LDO/晶振
3. HSI 内部时钟,无晶振,OSC 引脚悬空(Blue Pill 自带晶振,不影响)
4. 信号 GND 与功率 GND 在板子**单点共地(星形)**
5. H桥模块 5V 输出端不用,COM 必须接地
6. 所有信号线加下拉(复位时模块不动作)
7. 排母 J_MCU 位置预留 Blue Pill 投影区(53.3×22.5mm + 余量 ≈ 57×27mm),四周留 ≥2mm
8. 走线时 24V 与信号分层/分侧,避免干扰
