## 1. 项目一句话概述

大疆植保无人机(14S 电池)挂载油动鼓风机吹雪装置:STM32F103C8T6 统一控制 **24V 电动推杆**(升降风筒)+ **舵机**(控制油动鼓风机油门),由 **5V 光敏继电器模块** 信号触发整个工作循环(推出→吹风→收油门→缩回)。

**核心架构原则(多轮迭代后确认)**:光敏模块只提供状态信号,**STM32 统一控制**推杆和舵机,光敏继电器**不直接**切换推杆电机。

## 3. 引脚分配与固件逻辑(与 Keil 工程一致)

| MCU 引脚 | 功能 | 连接 |
|----------|------|------|
| PA0 | 光敏信号输入(上拉) | 光敏模块触点 |
| PA6 | TIM3_CH1 舵机 PWM (50Hz) | 舵机信号线 |
| PB12 | H桥 IN1(推杆伸出) | H桥 1# IN1 |
| PB13 | H桥 IN2(推杆缩回) | H桥 1# IN2 |
| PB14 | H桥 ENA(使能) | H桥 1# ENA1 |
| PA13/PA14 | SWD 下载 | ST-Link |
| PC13 | 板载 LED 状态指示(可选) | — |

**状态机**:`IDLE → EXTENDING(3s) → STABILIZE(500ms) → BLOWING(缓推油门2.5s) → STOPPING(缓收油门2.5s) → RETRACTING(3s) → IDLE`,异常 → `FAULT`(需人工复位)。

**可调参数**(main.c 顶部宏):`PULSE_WORK_US`(工作角度,默认2000μs)、`PULSE_MAX_US`(舵机上限,270°舵机改1833)、`EXTEND_TIMEOUT_MS`(5s)、`LIGHT_TRIGGER_LEVEL` 等。

### H 桥测试中遇到的问题(2026-08-08)

**现象**:① H桥 M+/M- 输出端测不到电压;② 信号端微热,有 0.13A 电流;③ GND↔PGND 单向导通(二极管特性)。

**分析**:
- 信号端 0.13A → 双H桥模块信号端(隔离+逻辑)典型功耗,**属正常**,不是故障
- GND↔PGND 二极管 → 隔离型设计正常特征
- **真正问题:输出无电压** → 待测:① 保险丝是否烧断(15A/10A);② 24V 是否真到模块;③ 光敏触发后 PB12/PB14 是否 3.3V;④ 1# 输出 A↔B 间测电压(非对地)

**待办**:完成测试 A(测 STM32 信号)→ 测试 B(测输出)→ 通过后接推杆无负载测试。

## 6. PCB 画板思路(供画板人,不含细节实现)

> 板子定位:**控制/保护接口板**(不是全功能单板)。DC-DC 模块、H桥模块、STM32 最小系统板均为外购模块,板子负责把它们安全地"接"起来。

### 6.1 板子功能分区

```
┌──────────────────────────────────────────────────────────┐
│  24V 输入区          │  5V 输入区          │  信号区       │
│  J1 (24V IN)         │  J3 (5V IN)         │  J8 光敏触点  │
│  F1 4A保险 → J2 H桥  │  F2 5A总保险        │  J10 舵机PWM  │
│  24V 滤波电容        │  F3 3A舵机→J4       │  J11 H桥控制  │
│                      │  F4 1A STM32→J5     │  保护电阻网络 │
│                      │  F5 0.5A光敏→J6     │  J5 排针座    │
│                      │  F6 0.5A H桥逻辑→J7 │  SWD 接口     │
└──────────────────────────────────────────────────────────┘
```

### 6.2 核心要求(画板人必读)

1. **尺寸**:约 100×70mm,2 层,2oz 铜厚(大电流必需),FR-4,1.6mm,4×M3 安装孔
2. **电流走线**:24V 主回路 ≥2mm 宽;5V 总线 ≥60mil(1.5mm)以上,避免压降
3. **保险丝**:6 路保险 F1~F6(4A/5A/3A/1A/0.5A/0.5A),5×20mm 卧式座,沿边排列方便更换
4. **滤波电容**:24V 侧 2200µF/35V + 1µF + 100nF;5V 侧 2200µF/10V + 1µF + 100nF,紧邻电源入口
5. **信号保护**(关键安全设计):
   - 光敏 PA0:10kΩ 上拉 + 1kΩ 串联 + 100nF 滤波
   - 舵机 PWM PA6:220Ω 串联 + 100kΩ 下拉(复位时防舵机误动)
   - H桥 IN1/IN2/ENA:各 1kΩ 串联 + 100kΩ 下拉(**MCU 复位期间推杆绝不动作**)
6. **接地**:底层整板 GND 覆铜(低阻抗回流);信号地与功率地在板内按 H桥模块要求处理(模块侧已隔离)
7. **丝印**:每个端子标注中文功能(J1=24V输入、J4=舵机供电等)+ J5 排针脚位定义,防接错
8. **测试点**:电源、信号、GND 关键节点预留测试点,方便调试
9. **可靠性**:大电流路径避免串联小过孔;保险丝座/电容/端子不得重叠;元件距板边 ≥3mm

### 6.3 接口定义(与现有接线方案一致)

| 端子 | 功能 | 连向 |
|------|------|------|
| J1 | 24V 输入 | DC-DC1 输出 |
| J2 | H桥功率(经 F1) | 双H桥模块 6.5~27V+/PGND |
| J3 | 5V 输入 | DC-DC2 输出 |
| J4 | 舵机供电(经 F3) | 舵机红/黑线 |
| J5 | STM32 排针 2×5 | Blue Pill(含供电/IO/SWD) |
| J6 | 光敏供电(经 F5) | 光敏模块 VCC/GND |
| J7 | H桥逻辑供电(经 F6) | 双H桥模块 +5V/GND |
| J8 | 光敏触点(COM/NO) | → PA0 |
| J10 | 舵机信号 | PA6 → 220Ω → 舵机信号线 |
| J11 | H桥控制 | PB12/13/14 → IN1/IN2/ENA1 |

> 注:双H桥模块的 2# 电机(IN3/IN4/ENA2)本项目不用,板上可不引出或预留。
