### H桥真值表(固件已实现)

| IN1 | IN2 | IN3 | IN4 | 电机 |
|-----|-----|-----|-----|------|
| 1 | 0 | 1 | 0 | 正转(伸出) |
| 0 | 1 | 0 | 1 | 反转(缩回) |
| 0 | 0 | 0 | 0 | 停止 |
| ⚠ 1&2 同高 / 3&4 同高 = MOS 烧毁(固件保证不会) |

### 状态机

```
IDLE → EXTENDING(3s) → STABILIZE(500ms) → BLOWING(6s缓推,最长30min)
     → STOPPING(6s缓收) → RETRACTING(3s) → IDLE
     任意异常 → FAULT(光敏恢复未触发 3s 人工复位)
```

## 4. 电源架构

```
大疆 14S 电池 (51.8V/58.8V, 18000mAh)
  ├─→ DC-DC1 (30~90V→24V/5A/120W,非隔离) ──→ H桥功率端 → 24V 推杆
  └─→ DC-DC2 (15~90V→5V/8A/40W,非隔离) ──→ STM32/舵机/光敏/H桥信号端
```

- 严禁 51.8V 直接进控制电路
- 星形接地拓扑,防信号地分流
- 高压侧:总开关/独立保险/防反接/线束绝缘,电池侧保险靠近取电端

## 5. PCB 设计任务(Codex 的活)

### 5.1 板子定位

**控制/保护/接口板**:DC-DC、H桥模块、STM32 最小系统、舵机、光敏均为外购模块,PCB 负责安全连接与信号保护。**板子本身不含 DC-DC 和 H桥功率部分**。

### 5.2 硬性规格

| 项目 | 要求 |
|------|------|
| 尺寸 | 约 100×70mm |
| 层数/铜厚 | 2 层 FR-4,2oz 铜 |
| 孔 | M3 安装孔 ×4(带机械禁布区) |
| 表面 | 绿油 + 有铅 HASL(参考既往下单) |
| 保险丝 | 6 路(见 5.4)+ 测试点 |

### 5.3 接口端子(丝印中文标注!)

| 端子 | 接到 | 保护 |
|------|------|------|
| J1: 电池 51.8V 输入 | DC-DC1/2 输入 | F 总保险 + 防反接 |
| J2: DC-DC1 输出 24V | H桥 6.5~27V+ | F1=4A |
| J3: 24V GND | H桥 PGND | 星形接地 |
| J4: DC-DC2 输出 5V | 5V 总线 | F2=5A |
| J5: 调试口 | SWD(PA13/14) | 非标口注意定义 |
| J6: 舵机 | 5V/GND/信号(PA6) | F3=3A,信号 RC 滤波(100Ω+10nF) |
| J7: 光敏 | 5V/GND/触点→PA0 | F5=0.5A,10k 上拉+1k 串+100nF |
| J8: H桥信号 | PA1/PA2/PA7/PA5/GND | 每组 1k 串+100k 下拉 |
| J9: H桥电源 | 24V+/PGND | F6=0.5A 逻辑?不,H桥功率 F 在外 |
| J10: 推杆 | H桥电机输出 | 10A 保险丝(外接) |
| J11/J12: 备用/测试点 | 电源/信号测试点 | — |

### 5.4 保险丝配置(全部外接或板上)

| 编号 | 位置 | 规格 | 保护 |
|------|------|------|------|
| F1 | DC-DC1 输出 → H桥电源 | 4A | 24V 总线 |
| F2 | DC-DC2 输出 → 5V 总线 | 5A | 5V 总线 |
| F3 | 5V → 舵机 | 3A | 舵机(堵转 ~1.5A×2) |
| F4 | 5V → STM32 | 1A | STM32 板 |
| F5 | 5V → 光敏 | 0.5A | 光敏 |
| F6 | 5V → H桥信号端(+5V 参考) | 0.5A | 信号端 |
| — | H桥电源输入(模块外接) | 15A | 模块功率 |
| — | H桥电机输出(模块外接) | 10A | 推杆 |

### 5.5 关键设计规则(既往审查教训!)

1. **保险座/电容/端子不得重叠**(装配物理碰撞)
2. **5V 主路径**:走线 ≥60mil,避免窄路径 + 串联小过孔(压降/温升瓶颈)
3. **全板 GND 覆铜**(之前缺)
4. 2oz 铜厚:过孔焊环 ≥0.254mm(37 个过孔按此)
5. 外部接口 J1/J2/J4/J6/J7/J8/J9 加 TVS/ESD 保护 + π 滤波
6. 舵机电源加本地储能(1000µF 电解,紧贴舵机端子)
7. 电机/舵机噪声是主要 EMI 源(不是高速信号)
8. 连接器/元件距板边 ≥3mm,M3 孔附近禁布
9. 丝印中文标注每个接口功能,防误插
