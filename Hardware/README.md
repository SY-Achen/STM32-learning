# 硬件资料 (Hardware)

本项目实际使用的硬件型号、参数与采购资料。每个子目录对应一个模块。

## 📦 模块清单

### 5A 单路 H 桥 (`5A单路H桥/`)
- 型号:**GZ-PMDC-120A7T**
- 输入:DC 12~27V | 额定 7A | 待机 ~3mA
- 4 信号真值表控制(IN1~IN4),光耦隔离,灌电流驱动
- 图片:产品参数、接线说明、真值表、经典接法

### 双路 H 桥 (`双路H路/`) — 已弃用
- 早期方案的双 H 桥大电流模块(6.5~27V),因端子与固件不匹配弃用
- 保留资料作参考

### 单片机 (`单片机/`)
- **STM32F103C8T6** 数据手册 (PDF)
- Blue Pill 最小系统板,64KB Flash / 20KB RAM

### 光敏开关 (`光敏开关/`)
- 5V 光敏继电器模块(暗时吸合)
- 8 张实物/接线截图

### 推杆 (`推杆/`)
- **普菲德电动升降杆** 数据手册 (PDF)
- 选用型号说明 (txt):24V,空载 0.7A / 有载 ≤2A / 峰值 2.5A,行程约 3 秒,内置双端限位

### 降压模块 (`降压模块/`)
- **30~90V→24V/5A/120W**(推杆 + H桥功率)
- **15~90V→5V/8A/40W**(控制电路 + 舵机 + 光敏)

## ⚠️ 使用注意

- H 桥真值表禁止 IN1&IN2 或 IN3&IN4 同时为高(烧 MOS)
- 信号端 GND 与功率端 PGND 不共地(隔离型)
- 模块电源 12~27V,不可接反
